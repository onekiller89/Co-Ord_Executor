# Unverified YouTube extractions

These 36 files were generated with the `grok_api` method, which sent a YouTube URL to a language model without a video transcript. A 23 September 2026 audit retrieved YouTube oEmbed titles for all 69 YouTube records and found repeated source/content contradictions in this cohort. All 36 are quarantined as a precaution, including records whose summaries look plausible. None has been validated against its actual video transcript.

The original Markdown files remain here unchanged. `manifest.json` records the source URL, metadata title at audit time, original index category, tags and status. The active `INDEX.md` marks 48 affected rows as `Unverified` while retaining their original status values. Some rows share a filename because earlier extraction writes collided; the manifest preserves each original row.

Do not use these summaries as source evidence. Re-extract from captions tied to the video ID, compare the result with the source, then replace or restore an index entry only after verification.
